# NextRole — Nuxt SaaS Landing Page

A fictional portfolio concept demonstrating conversion copywriting, UX design, responsive frontend development, and SaaS product positioning.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Generate a static build

```bash
npm run generate
```

Nuxt will create the deployable site in `.output/public`.

## Included

- Responsive marketing landing page
- Mobile navigation
- Interactive workspace preview modal
- Product dashboard mockup built in HTML and CSS
- Benefits, process, AI transparency, FAQ, and conversion sections
- Search-friendly title and meta description

## Portfolio notice

NextRole is a fictional SaaS concept. It should be presented as a concept project, not as a real client engagement or functioning job-search service.
